## V9.4 旧存档兼容
这一版重点修复“网站更新后旧存档读取了却无法继续”的问题。

原因：
旧版本剧情使用了 `chapter1_XX / route_c_XX / hunt_XX` 等节点 ID，
后续整理剧本断句时曾改成新的 `ch1_XXX / prologue_XXX`，
浏览器 localStorage 中的旧存档仍然记着旧 ID。

现在：
- V6 / V7 / V8 的主要旧节点会自动迁移到当前节点。
- 旧版 `chapter1_end` 会直接迁移到 `chapter2_intro`，因此可以继续进入第二章。
- 旧版斗兽场下注的 A/B 选择仍然保留，并根据 `arenaBet` 自动进入对应剧情。
- 姓名、黑化/救赎/野心/依附数值、历史记录都会保留。
- 旧版第一章 BGM 文件名也会自动迁移到当前文件名。
- 读一次旧存档后，该存档会自动写回为新版格式。
- 后续版本应尽量保持已经发布过的节点 ID 稳定，不再因断句修改而破坏存档。
