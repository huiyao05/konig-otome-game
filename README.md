# 一、怎么加背景图

把图片放到：

`assets/backgrounds/`

当前剧情已经预留：
- `title.jpg` 标题页
- `forest-autumn.jpg` 皇家秋猎 / 森林整体
- `forest-path.jpg` König 被欺负的树林
- `bad-ending.jpg` BAD END

建议使用竖图：
- 1080 × 1920
- 1440 × 2560
- 或其他 9:16 比例

例如你有一张图片叫：

`royal-hunt.jpg`

把它放进 `assets/backgrounds/` 后，在 `story.js` 里写：

```js
bg: "royal-hunt.jpg",
```

这一段剧情就会显示这张图片。

---

# 二、怎么加背景音乐

把 MP3 放到：

`assets/audio/`

当前已经预留：
- `title.mp3` 标题页音乐
- `forest.mp3` 序章森林音乐
- `bad-ending.mp3` BAD END 音乐

例如：

```text
assets/audio/forest.mp3
```

然后某一个剧情节点写：

```js
bgm: "forest.mp3",
```

音乐就会从这里开始播放。

只要后面的剧情没有指定新的 `bgm`，当前音乐就会继续播放，不会每一句重新开始。

如果后来写：

```js
bgm: "palace-night.mp3",
```

就会切换成新的音乐。

## 手机浏览器注意
Safari / Chrome 通常不允许网页“完全自动”播放声音。
玩家第一次点「开始游戏」或点击页面后，音乐才会真正开始，这是浏览器的正常限制。

右上角有：
- `♫` 音乐开启
- `♩` 音乐关闭

# 四、四个数值

- `dark` 黑化值
- `redemption` 救赎值
- `ambition` 野心值
- `dependence` 依附值

例：

```js
effects: { redemption: 2, ambition: 1 }
```

# V4 更新

## 1. 姓名输入页
点击“开始游戏”后：
- 标题背景消失
- 姓名输入页使用纯黑背景
- 不会提前出现森林图
- 输入姓名并确认后，仍在黑屏上播放“序章 / 困兽”章节动画
- 动画结束才正式切到森林背景

## 2. BAD END
A / B 进入坏结局后：
- 播放 `bad-ending.mp3`
- 隐藏游戏菜单
- 结局画面只有“返回标题”
- 不能在 BAD END 画面直接读档
- BAD END 不会覆盖自动存档
- 返回标题后再使用“继续游戏”或“读取存档”

## 3. 读档音乐修复
存档现在会记录当时正在播放的 BGM。
读取存档后，会先恢复对应 BGM，再恢复剧情。

因此从 BAD END 返回标题再读取森林存档时，
会重新播放 `forest.mp3`，不会继续坏结局音乐。

## 4. C 线新音乐
选择 C 后，从 `route_c_01` 开始自动切换为：

`assets/audio/route-c.mp3`

把你的 C 线新音乐改名为 `route-c.mp3` 放进去即可。

# V5 更新

## 标题音乐
- 标题页仍使用 `assets/audio/title.mp3`
- 网页第一次打开时会尝试播放标题音乐
- 如果 Safari / Chrome 因自动播放规则拦截，玩家第一次触碰标题页时会再次启动标题音乐
- 从剧情或结局返回标题页时，`title.mp3` 会正常恢复
- 点击“开始游戏”进入姓名输入页后，标题音乐可以继续播放
- 输入姓名并确认后，标题音乐停止；序章动画结束后切换到森林音乐

说明：手机浏览器无法保证“用户完全没碰网页时就自动发出声音”，这是浏览器限制，不是游戏代码故障。

## 回看记录
回看顺序改为：
- 最早说过的话在最上面
- 后来的话依次往下
- 最新一句在最下面

不再倒序显示。
